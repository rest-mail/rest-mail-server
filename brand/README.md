# REST Mail brand

The one copy of REST Mail's icon. Everything that shows the icon takes it
from here: the mobile app, the website, the webmail and admin UIs, and the
GitHub organisation. The mobile app and the website are separate
repositories, so they carry a copy of these files; when the icon changes,
change it here first and copy it on.

## Icon

| File | Size | Use |
| --- | --- | --- |
| `icon/rest-mail-icon.svg` | vector | the source; favicons and anything that scales |
| `icon/rest-mail-icon-1024.png` | 1024 × 1024 | App Store, and the source for app icon sizes |
| `icon/rest-mail-icon-512.png` | 512 × 512 | Android, GitHub avatar |
| `icon/rest-mail-icon-180.png` | 180 × 180 | Apple touch icon |
| `icon/rest-mail-icon-32.png` | 32 × 32 | PNG favicon |

a green check.
